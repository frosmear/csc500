Create a ItemToPurchase Class
    Initialize method
        Set item name to the provided name.
        Set item price to the provided price.
        Set item quantity to the provided quantity.

    Define a Print Item Cost Method
        Multiply the item price by the item quantity.
        Display the item name, quantity, price, and total cost.

Create a ShoppingCart Class
    Initialize method
        Set the customer name.
        Set the current date.
        Set an empty list called cart_items.

    Define Add Item method
        Receive an ItemToPurchase object.
        Add the object to cart_items.

    Define Remove Item method
        Search cart_items for an item with the requested name.
        If the item is found, remove it.
        If the item is not found, display warning message

    Define Modify Item method
        Search cart_items for an item with the requested name.
        If the item is found, update its price and quantity.
        If the item is not found, display warning message.

    Define Get Number of Items method
        Start a quantity counter at zero.
        Loop through every item in cart_items.
        Add each item's quantity to the counter.
        Return the total quantity.

    Define Get Cost of Cart method
        Start a total cost counter at zero.
        Loop through every item in cart_items.
        Multiply each item's price by its quantity.
        Add each item total to the cart total.
        Return the total cost.

    Define Print Total method
        Display the customer's name and current date.
        Check whether the cart is empty.
        If the cart is empty, display warning and stop
        Print each item and its cost.
        Display the total number of items and total cost.

    Define Print Descriptions method
        Display the customer's name and current date.
        Check whether the cart is empty.
        If the cart is empty, display warning and stop
        Loop through the cart and display each item's name.

Create a RetailStore Class
    Initialize method
        Set the store name.
        Create a ShoppingCart object

    Define a get customer info method
        Ask the user for the customer's name.
        Ask the user for the date they want to buy, default to now
        Validate inputs and update cart object

    Define a Display Menu method
        Define a function that prints the menu
            Display options for:
                Add item
                Remove item
                Change item quantity
                Output descriptions
                Output shopping cart
                Quit

        Print the menu using the function
        Until they pick a valid option:
            Ask the user to select an option.
            Exit loop if quit is selected
            If the option is valid execute the appropriate method on ShoppingCart
            Else display an invalid-option message.
            Display the menu again

Main Function
    Initialize a RetailStore class
    Call the get customer info method
    Call the Display Menu method
