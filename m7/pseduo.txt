Set up dictionaries containing LUT data
Avoid temptation to do this with JSON
  Create a dictionary containing each course number and its room number.
  Create a second dictionary containing each course number and its instructor.
  Create a third dictionary containing each course number and its meeting time.

Ask the user to enter a course number.

Remove unnecessary spaces from the beginning and end of the input.
Convert the course number to uppercase so entries such as csc101 are easier to handle.

Check whether the course number exists in each dictionary.

If the course does not exist:
    Display a friendly error message.
    End the program.

If the course exists:
    Retrieve the room number using the course number.
    Retrieve the instructor using the course number.
    Retrieve the meeting time using the course number.

Display the course number, room number, instructor, and meeting time.
